# Brain-Tumor-Detection-using-DL
A deep learning system that classifies brain MRI scans into glioma, meningioma, pituitary tumor, or no tumor, using a hybrid ConvNeXt–Swin Transformer architecture with cross-attention fusion and confidence-guided refinement. Achieves 95.75% test accuracy, with Grad-CAM visualizations for interpretability. Built with PyTorch.
